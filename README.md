# Web Project

A Next.js web application set up with App Router, TypeScript, and Tailwind CSS, ready for deployment on [Vercel](https://vercel.com).

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `src/app/page.tsx` - Home page ("Project is under construction")
- `src/app/layout.tsx` - Root layout
- `src/app/globals.css` - Global styles (Tailwind CSS)

## Vercel Deployment

This project is pre-configured for automatic deployment on Vercel:
1. Push to your GitHub repository.
2. Import the repository into Vercel.
3. Vercel will automatically detect Next.js and deploy.
